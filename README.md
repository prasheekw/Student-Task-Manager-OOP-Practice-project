# Student Task Manager

A small Python OOP project for managing student tasks.

## Features

- Add tasks
- View tasks
- Mark tasks as completed
- Delete tasks
- Basic input validation

## Concepts Practiced

- Classes and objects
- Encapsulation
- Properties and setters
- Composition
- Instance methods
- Lists of objects
- Exception handling

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Run:

```bash
python main.py
